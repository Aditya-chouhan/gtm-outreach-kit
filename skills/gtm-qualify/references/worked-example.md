# Working template and review example

```text
Record ID
Company fit
Person fit
Criterion/type/finding/source/date
Overall disposition and rule
Unknowns/conflicts
Contact readiness separately
Evidence that changes the decision
```

## Review example

**Request:** An investor liked three posts; qualify them as a buyer.

**Expected behavior:** Evaluate the buyer rubric and preserve any investor exclusion; engagement does not establish fit or authority.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
