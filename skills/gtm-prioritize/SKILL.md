# Prioritize qualified prospects

Read [priority mechanics](references/priority.md). Start with a saved run and its configured preferences, relevant signal types, and evaluation date.

Use the engine's priority fields. Explain who ranks above whom using the actual preference matches and eligible dated signals. Compare a few neighboring records to make the ordering inspectable. Do not invent a probability, weighted score, or expected revenue from the rank.

Review ignored signals too: duplicates, irrelevant types, missing sources or dates, stale events, and future observations. If signal types or freshness should change, make that a visible brief edit and rerun into a new directory. Distinguish hypothetical ranking from an observed rerun.

Never promote excluded or review records because they have many signals. A high-fit suppressed record can still have a fit rank, but remains blocked from draft generation. Return a contactable shortlist with the suppressed distinction visible, the reasons for ordering, and the remaining review work.
