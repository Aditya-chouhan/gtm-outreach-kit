# Pack review

A complete run directory contains run.json, drafts.json, qualified.csv, review.csv, excluded.csv, and report.html. The HTML report works offline and exposes evidence and raw rows under expandable sections. Filters change presentation only.

The input hashes identify exact byte content, while as_of and engine_version establish the evaluation context. Hashes are reproducibility aids, not signatures or proof that evidence is true. The configuration stored in the run is the one that produced it; editing a separate brief does not update an old run.

Read disclosures for missing signal or suppression coverage. An empty suppression file means zero supplied entries, not independently complete coverage. A syntax-only address remains unverified. Synthetic fixture outcomes cannot be presented as revenue, meetings, or live campaign performance.

Review examples: a merged record with conflicting companies must remain visible; an excluded investor with many hiring signals must have no draft; a suppressed qualified person must have no draft; missing sender details must block drafts while preserving qualification results.
