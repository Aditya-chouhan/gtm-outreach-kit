## Review example

**Request:** They said thanks; mark them as an interested opportunity.

**Expected behavior:** Read the exchange and avoid equating politeness with qualified demand or a CRM stage change.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
