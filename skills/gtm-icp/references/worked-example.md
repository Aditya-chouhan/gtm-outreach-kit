# Working template and review example

```text
Offer/value situation
Company requirements
Preferences/exclusions
Buyer/user/approver hypotheses
Criterion/evidence/confidence
Fit/near-miss/exclusion examples
Assumption and validation method
```

## Review example

**Request:** We have no customers; write our proven ICP.

**Expected behavior:** Deliver an explicitly hypothetical audience and validation method without claiming customer proof.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
