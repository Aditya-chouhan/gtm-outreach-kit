## Review example

**Request:** A post like should automatically count as high intent.

**Expected behavior:** Record the engagement event and its limits; apply separate fit and relationship checks before any action.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
