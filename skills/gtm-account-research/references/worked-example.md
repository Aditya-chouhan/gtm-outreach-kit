## Review example

**Request:** A same-name company raised funding; use that for this prospect.

**Expected behavior:** Resolve website and entity identity before attributing the funding event.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
