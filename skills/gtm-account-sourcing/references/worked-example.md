# Working template and review example

```text
Audience/scope
Criterion/source filter/applied or unsupported
Source/query/date/quote
Account/company/domain/source/fit evidence/unknowns
Duplicates and coverage gaps
```

## Review example

**Request:** Find every company in the market, but the tool only exposes fifty.

**Expected behavior:** Report the accessible sample and coverage limits without claiming complete market coverage.

Inspect the actual generated artifact and any claimed external effects. An instruction file containing the desired wording is not proof of assistant behavior.
