# Skill catalog

25 original, standalone GTM agent skills by Aditya Chouhan. Select the narrowest skill for the job. External capabilities depend on the tools actually connected to the agent; no skill requires the bundled CLI.

| Skill | When to use it |
| --- | --- |
| [gtm-brief](../skills/gtm-brief/SKILL.md) | Create or revise an operational GTM brief from company, offer, buyer, goals and constraints. Use at the start of an engagement or when context changes; not for campaign performance diagnosis. |
| [gtm-icp](../skills/gtm-icp/SKILL.md) | Define or refine ideal customer and buyer criteria from customer and sales evidence. Use for segmentation and audience design; not grading records against an established rubric. |
| [gtm-positioning](../skills/gtm-positioning/SKILL.md) | Develop positioning, value propositions and offer language from buyer evidence and actual alternatives. Use for offer clarity and differentiation; not full outreach cadence design. |
| [gtm-diagnose](../skills/gtm-diagnose/SKILL.md) | Diagnose a specific GTM performance problem from company context, funnel evidence and raw examples. Use for flat pipeline or weak conversion; not routine weekly reporting. |
| [gtm-account-sourcing](../skills/gtm-account-sourcing/SKILL.md) | Find or assemble target accounts from an agreed audience using accessible approved sources. Use for company sourcing and coverage planning; not personal contact enrichment. |
| [gtm-account-research](../skills/gtm-account-research/SKILL.md) | Research a named company for a specific GTM question using accessible sources. Use for account dossiers and account-specific hypotheses; not bulk contact enrichment. |
| [gtm-buyer-map](../skills/gtm-buyer-map/SKILL.md) | Map users, champions, owners and approvers at a named account using current organizational evidence. Use for buying-group research; not mass email discovery. |
| [gtm-enrichment-plan](../skills/gtm-enrichment-plan/SKILL.md) | Plan or audit enrichment of existing contact/account records with identity checks, supplier constraints and verification states. Use for specific data gaps; not company sourcing or sending. |
| [gtm-data-inspect](../skills/gtm-data-inspect/SKILL.md) | Inspect prospect exports for column ambiguity, missing evidence, malformed values and duplicate identities. Use before qualification or imports; not live CRM cleanup. |
| [gtm-qualify](../skills/gtm-qualify/SKILL.md) | Assess company and person fit against an explicit evidence-based rubric. Use for prospect qualification; not signal ordering or market sizing. |
| [gtm-prioritize](../skills/gtm-prioritize/SKILL.md) | Order an already-qualified prospect or opportunity queue using explicit preferences, demand and dated signals. Use to choose the next work; not to establish fit or predict purchase probability. |
| [gtm-signal-design](../skills/gtm-signal-design/SKILL.md) | Design GTM event definitions, source coverage, freshness and review actions. Use before building monitoring or event routing; not ranking individual prospects. |
| [gtm-draft](../skills/gtm-draft/SKILL.md) | Write or revise first-touch email/direct-message drafts from supplied buyer context, offer and evidence. Use for exact copy; not cadence scheduling or live sending. |
| [gtm-sequence-design](../skills/gtm-sequence-design/SKILL.md) | Design multistep outreach channel logic, waits, reply handling and stop conditions. Use for cadence architecture; not message copy alone or unrequested enrollment. |
| [gtm-review](../skills/gtm-review/SKILL.md) | Review an outreach pack for identity, fit, suppression, sender, copy, schedule and blockers. Use before campaign handoff or launch; does not launch or certify compliance. |
| [gtm-crm-hygiene](../skills/gtm-crm-hygiene/SKILL.md) | Audit CRM records for duplicate identity, lifecycle, ownership and relationship problems. Use for hygiene and repair planning; not cosmetic export formatting or unsolicited live merges. |
| [gtm-deliverability](../skills/gtm-deliverability/SKILL.md) | Investigate sender, authentication, bounce and delivery evidence for a reported email problem. Use for troubleshooting; not inbox-placement guarantees or automatic infrastructure changes. |
| [gtm-reply-triage](../skills/gtm-reply-triage/SKILL.md) | Triage supplied or connected sales threads and draft context-aware responses. Use for inbox review; not new outreach or automatic sending. |
| [gtm-meeting-handoff](../skills/gtm-meeting-handoff/SKILL.md) | Prepare an accurate sales meeting brief and ownership handoff from conversations and account evidence. Use after interest or booking; not calendar scheduling. |
| [gtm-pipeline-analysis](../skills/gtm-pipeline-analysis/SKILL.md) | Analyze pipeline, campaign or opportunity exports with defined cohorts, denominators and time windows. Use for performance analysis; not unsupported causal attribution. |
| [gtm-experiment](../skills/gtm-experiment/SKILL.md) | Design a bounded GTM experiment or evaluate it against a declared decision rule. Use for audience, offer, channel or copy tests; not retrospective winner selection from uncontrolled changes. |
| [gtm-linkedin-content](../skills/gtm-linkedin-content/SKILL.md) | Plan or draft LinkedIn posts from actual author expertise, evidence and audience needs. Use for original professional content; not automated engagement or unrequested publishing. |
| [gtm-content-repurpose](../skills/gtm-content-repurpose/SKILL.md) | Adapt existing source material into GTM posts, emails, briefs or carousel outlines while preserving meaning and attribution. Use for repurposing; not original research or automatic publishing. |
| [gtm-workflow-design](../skills/gtm-workflow-design/SKILL.md) | Design, review or debug GTM automation with data contracts, state, identity and failure handling. Use for workflow architecture; not claiming that a diagram implements an integration. |
| [gtm-operating-review](../skills/gtm-operating-review/SKILL.md) | Prepare a periodic GTM review from metrics, commitments and prior decisions. Use for weekly cadence and ownership; not inventing progress or replacing a focused diagnosis. |

## Task routing

Brief, ICP and positioning establish the proposed audience and offer. Sourcing, research and buyer mapping build evidence. Data inspection, qualification, prioritization, drafting, sequence design and readiness review prepare outreach. Reply triage and meeting handoff continue actual conversations. Pipeline analysis, experiments and operating reviews support learning and ownership. Content and workflow tasks run when requested, not automatically in every engagement.

A catalog is not an autonomous campaign. Plans, drafts, execution and verified outcomes remain distinct.
